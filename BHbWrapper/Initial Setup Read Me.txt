==============================================================================
  INITIAL SETUP READ ME  -  BHbWrapper (add-on for the Bit Heroes bot)
==============================================================================

WHAT THIS IS
  A window (the "BH Bot Controller") that plays Bit Heroes for you: it fishes,
  and it runs the "AFK" chain (quests, PVP, World Boss, Raid, Trials, Gauntlet,
  Invasion, and so on). It works on top of the free Bit Heroes bot by "9-9-9-9".

WHAT YOU NEED
  - A Windows PC
  - Google Chrome (the normal one, already installed)
  - A Kongregate account that can already play Bit Heroes in your browser:
      https://www.kongregate.com/games/Juppiomenz/bit-heroes
  - An internet connection for the first start (it installs a few things)

  IMPORTANT - CHROME ONLY:
    This setup works only with the Chrome / Kongregate version of the game.
    The Steam version is NOT supported.
  YOU DO NOT NEED JAVA.

------------------------------------------------------------------------------
  STEP 1 - DOWNLOAD THE ORIGINAL BOT
------------------------------------------------------------------------------
  1. Open:  https://github.com/9-9-9-9/Bit-Heroes-bot
  2. On the right side click "Releases" (or open
       https://github.com/9-9-9-9/Bit-Heroes-bot/releases/latest ).
  3. Under "Assets" download the .zip file made for normal users. It is
     usually named  download-this-file.zip  (the original author's own wording).
     Do NOT use the green "Code" > "Download ZIP" button: that is the source
     code and it does not contain BitHeroes.jar.
  4. TIP: before extracting, right-click the downloaded .zip > Properties and
     tick "Unblock" at the bottom (if you see it), then click OK.
  5. Right-click the .zip > "Extract All..." and choose a simple place, for
     example your Documents folder. You get a folder with a name like
     "99bot-v3.7.5". This is called "THE BOT FOLDER" below.

  When you open the bot folder you should see, among others:
       sample-scripts     (a folder)
       BitHeroes.jar
       user-config.properties

------------------------------------------------------------------------------
  STEP 2 - PUT THE ADD-ON IN THE BOT FOLDER
------------------------------------------------------------------------------
  Unzip the add-on download (BHbWrapper.zip). Put BOTH of these into THE BOT
  FOLDER, right NEXT TO the "sample-scripts" folder:

       - the folder   BHbWrapper
       - the file     start_gui.bat

  It must look like this:

       99bot-v3.7.5\
          sample-scripts\          <- the original's folder
          BitHeroes.jar
          user-config.properties
          BHbWrapper\              <- put this here
          start_gui.bat            <- and this here

  Do not put them inside sample-scripts, and do not rename BHbWrapper.

------------------------------------------------------------------------------
  STEP 3 - START THE WINDOW (first start installs what is needed)
------------------------------------------------------------------------------
  1. Double-click  start_gui.bat
  2. If Windows says "Windows protected your PC": click "More info", then
     "Run anyway".
  3. The first time, it checks for Python and installs it if missing, then
     installs a few Python packages. This can take several minutes.
       - If Windows asks "Do you want to allow...", click Yes.
       - If it says Python was just installed, close the black window and
         double-click start_gui.bat once more.
       - Leave the black window open while the bot window is in use; it is
         part of the program.
  4. The "BH Bot Controller" window opens. If it asks you to select the bot
     folder, pick THE BOT FOLDER from Step 1 (the one with BitHeroes.jar).

------------------------------------------------------------------------------
  STEP 4 - LINK YOUR GAME ACCOUNT  (button: "Initial Setup Help")
------------------------------------------------------------------------------
  Click the "Initial Setup Help" button and follow the four steps in it:
    1. "Open Kongregate in Chrome" - log in to Kongregate and wait until Bit
       Heroes has loaded in that tab. Keep the tab open.
    2. "Copy the console script" - then, in that Chrome tab press F12, click
       the "Console" tab, press Ctrl+V and Enter. (If Chrome says pasting is
       blocked, type   allow pasting   press Enter, then paste again.)
       You should see three lines starting with 1.game.kong...
    3. Click "Paste from clipboard", choose account number 1, and click
       "Save to user-config.properties". A backup of your old file is kept.
    4. Click "Create the game files". It should say "created ...index1.html".
  Then close the little window.

  If nothing shows up in the Console, or only the word "undefined":
    - Click the little filter box in the Console toolbar and make sure it is
      EMPTY (an old filter hides the answer).
    - Open the "Default levels" menu and make sure "Info" is ticked.
    - The word "undefined" on a line by itself AFTER the three lines is normal.
    - Make sure you are on the Kongregate Bit Heroes page and logged in.

  KEEP YOUR TOKEN PRIVATE. The line "1.game.auth.token=..." in
  user-config.properties works like a password for your game account. Never
  post that file, or a screenshot of it, anywhere. If the bot later says it
  cannot log in, your token expired (it changes when you log out of
  Kongregate): just do Step 4 again.

------------------------------------------------------------------------------
  STEP 5 - FIRST RUN (get you feet wet)
------------------------------------------------------------------------------
  1. In the "Script" box choose   BHbWrapper/Fish.bat  and in the "Then run" 
     choose   BHbWrapper/AFK.bat. Click Start.
     
     A small game window opens by itself and logs in. Watch it fish for a bit.
     (Fish.bat fishes 18 times at default until you update the number, while 
     AFK.bat runs through the various available events.)
  2. Want to test the bot without the bot actually clicking anything? Use 
     BHbWrapper/AFK.watch.bat; It only tells you what it sees and would do.
  4. Use the buttons in the middle (Quest, PVP, World Boss, Raid, Trials,
     Gauntlet, GVG, Expedition, Invasion) to choose what each event should do.
     A dot on a button means its settings are switched on. You can change them
     while the bot is running. These are only the overrides when enabled, your 
     default account settings are the default.

  Handy: "Force Stop" ends the bot at once. "Pause" freezes it. "Compact log"
  hides repetitive messages. The "Full restart every ... min" box restarts the
  game and the bot on a timer (0 = never), and the drop-down next to it chooses
  what happens if the screen gets stuck.
  If the game says it is down for maintenance, the bot closes the game and the
  window starts again by itself after the number of minutes you set (60).

------------------------------------------------------------------------------
  IF SOMETHING GOES WRONG
------------------------------------------------------------------------------
  "Chrome not found"            Use the "Initial Setup Help" window: it asks you
                                to pick chrome.exe if it cannot find it. Or add
                                a line to user-config.properties:
                                external.application.chrome.path=C:\\Program Files\\Google\\Chrome\\Application\\chrome.exe
  "Python not found"            Close everything and run start_gui.bat again.
  Window opens, game is blank   Close the game window, then press Start again.
  Bot seems stuck               Screenshots are saved in  BHbWrapper\out\unknown
                                (cover your name and never include the token
                                when you ask for help).
  Settings seem ignored         Delete  BHbWrapper\overrides.json  to go back to
                                the defaults.
  Nothing helps                 Run start_gui.bat again; the black window shows
                                error messages you can copy (hide your token).

------------------------------------------------------------------------------
  WHICH FILES ARE USED, WHICH ARE LEGACY
------------------------------------------------------------------------------
  USED by this add-on (keep these):
    start_gui.bat                    opens the window (installs Python etc.)
    BHbWrapper\bh_gui.py             the controller window
    BHbWrapper\bh_setup.py           the "Initial Setup Help" window
    BHbWrapper\bhbot.py              the bot itself
    BHbWrapper\templates\            what the bot recognises on screen
    BHbWrapper\Fish.bat, AFK.bat, AFK2.bat, AFK.watch.bat, Esc.bat
                                     the scripts you pick in the Script box
    BHbWrapper\overrides.json        made by the buttons (settings)
    BHbWrapper\out\                  screenshots / evidence the bot saves
  From the ORIGINAL bot folder, still used:
    user-config.properties           your account (id, name, token), optional
                                     Chrome path
    user-config.properties.bak       the backup made by the setup window
    readonly.<name>.user-config.properties
                                     optional per-account settings profile, if
                                     you already have one (it is not required)
    bh-client\                       the two game script files; the game page
                                     files are written here
    BitHeroes.jar                    only checked for (so the window knows it is
                                     in the right folder) and used as a spare
                                     source of the two script files. Keep it.
    chrome-user-dir\                 the bot's own Chrome profile, created
                                     automatically on first run

  LEGACY (original Java bot - NOT used by this add-on; safe to ignore):
    _.bat, bot.sh, web.bot.bat, steam.bot.bat, AFK.web.bat, AFK.steam.bat,
    help.bat, help.sh, setting.bat, setting.sh, client.bat, client.sh,
    prepare-mini-chrome-client.txt, the sample-scripts folder, and the
    original's own "out" folder. All of these need Java, which this add-on does
    not use. (setting.bat only made the optional readonly profile; the buttons
    in the window replace it. client.bat made files this add-on creates itself.)
    Do not delete them if you also want to use the original Java bot.

------------------------------------------------------------------------------
  GOOD TO KNOW
------------------------------------------------------------------------------
  - This is an unofficial community tool. Automating a game may be against its
    rules. You use it at your own risk.
  - The bot takes pictures of the game window to decide what to click, so
    updates to the game can break parts of it until it is updated.
  - Credit: the original bot and its ideas are by 9-9-9-9
    (https://github.com/9-9-9-9/Bit-Heroes-bot).
